Business Intelligence Project

Business Analytics Site

A web-based analytics presentation that organizes process analysis, operations analysis, decision analysis, and dashboard thinking into a cleaner decision-support experience.

Live Site Repository

This project was built to present analytical material in a format that is easier to navigate than a static document. It connects coursework-style analysis with web presentation: structured pages, clear navigation, and reporting concepts that make technical findings easier to scan.

The work reinforced two related skills: building a responsive front-end and shaping business analysis so a reader can follow the logic from process context to operational implications and decision support.

What it demonstrates

  • Organized multi-page content for analytical topics.
  • Responsive HTML and CSS with Bootstrap-era layout patterns.
  • Power BI-style dashboard thinking and visual storytelling.
  • Ability to turn analysis into a usable web presentation.
